# مخطط التحضير الذكي – Lesson Planner

تطبيق Android (Flutter) يعرض لك **تحضير كل حصة جاهزاً حسب جدولك الأسبوعي وخطط الصفوف**، بتخزين محلي (SQLite) ويعمل دون إنترنت.
مُعدّ لمعلم الحاسوب أحمد داود طه شريف – مدارس الفجر الأهلية – الفصل الدراسي 17 أكتوبر 2026 ← 20 يناير 2027 (14 أسبوعاً).

> **حالة هذا الإصدار:** كُتب الكود كاملًا لكنه **لم يُبنَ ولم يُختبر** (لم تتوفر أدوات Flutter/Android في بيئة الإنشاء).
> نفّذ الخطوات في «التحقق قبل الاستخدام» وأصلح أي خطأ تجميع قبل الاعتماد عليه فعليًا.

## الاستيراد والتشغيل (Klencod IDE)
1. افتح هذا المجلد كمشروع Flutter (يحتوي pubspec.yaml ومجلد android).
2. شغّل: `flutter pub get`
3. جهاز Android حقيقي (يُفضّل) ثم: `flutter run`
4. لبناء APK: `flutter build apk --release` ← الناتج: `build/app/outputs/flutter-apk/app-release.apk`

إن اشتكى IDE من غياب `android/local.properties` أو ملفات Gradle wrapper فشغّل مرة واحدة:
`flutter create --platforms=android --project-name lesson_planner .`
(يُكمل الملفات الناقصة دون المساس بـ lib، وإن سأل عن استبدال ملفات فاحتفظ بملفاتك).

## التحقق قبل الاستخدام
```
flutter pub get
dart format lib test
flutter analyze
flutter test
flutter build apk --release
```
اختبارات `test/` تغطي: ترتيب الأيام ومدة الحصة (35/45)، توزيع الدقائق، سلامة بيانات المنهج (112 تحضيراً)، ربط التاريخ بالدرس (العطل والحصص الملغاة والإزاحة)، والنسخ الاحتياطي. وهي مكتوبة ولم تُشغَّل بعد.

## طريقة الاستخدام
1. **عند أول تشغيل** يسألك التطبيق: هل أُعطيت حصص السبت 17 أكتوبر؟ الجواب يحدد أي درس تبدأ به كل شعبة (يمكن تغييره من الإعدادات).
2. **اليوم**: حصص اليوم (أو أقرب يوم دوام) مرتبة حسب الحصة، اضغط أي حصة لفتح تحضيرها. بعد الساعة المحددة في الإعدادات يعرض التطبيق دوام الغد تلقائياً.
3. **التحضير**: كل الحقول مطابقة لنموذج تحضيرك (المعلومات الأساسية، الأهداف بمجالها ومستواها، عناصر المحتوى ونشاط المعلم والمتعلم والزمن والاستراتيجية، المصادر، التقويم والواجب، التأمل الذاتي، طموح تطوير الذات). كل حقل قابل للتعديل والنسخ، وزر لنسخ التحضير كاملاً. مجموع أزمنة العناصر = مدة الحصة (35 دقيقة السبت والأحد، 45 بقية الأيام).
4. **الجدول**: شبكة الأسبوع بألوان الصفوف.
5. **الدروس**: مكتبة كل صف بأسابيعه الـ14 (حصتان لكل أسبوع: شرح ثم تطبيق).
6. **الإعدادات**: الاسم والمدرسة، تاريخ البدء، إزاحة تسلسل كل شعبة، العطل، الحصص التي لم تُعقد (يتحول محتواها للحصة التالية)، النسخ الاحتياطي (نسخ/لصق أو ملفات JSON داخل مجلد التطبيق)، وحذف كل تعديلاتك.
7. **الشعبة بلا خطة (12ب)**: يفتح تحضير يدوي فارغ تعبّئه بنفسك.

## البيانات
- 4 صفوف × 14 أسبوعاً × حصتان = **112 تحضيراً** مولّدة مسبقاً داخل `lib/data/curriculum_data.dart`.
- خطط الصفوف 4 و5 و8 منقولة من الخطط الفصلية المرفقة. **خطة الصف التاسع مقترحة** (وحدة ذكاء اصطناعي واستخدام ذكي للتقنية) لعدم وجود منهج رسمي.
- أسماء أدوات الصف الثامن (التصميم) كُتبت بالعربية مع الإنجليزية بين قوسين، راجعها مع الكتاب.
- قوائم المجال والمستوى في الأهداف (معرفي/مهاري/وجداني) وُضعت بافتراض مني؛ قارنها بقوائم تطبيق التحضير لديك وعدّلها في `lib/utils/constants.dart` إن اختلفت.
- التعديلات والتأملات والعطل تُحفظ في SQLite المحلية ولا تُرسل لأي جهة.

## الصلاحيات
لا يطلب التطبيق أي صلاحية خاصة (لا إنترنت ولا موقع ولا إشعارات). النسخ بالملفات يُحفظ في مجلد التطبيق الخارجي `Android/data/com.alfajr.lessonplanner/files/backups`.

## القيود المعروفة
- حذف التطبيق أو مسح بياناته يمسح تعديلاتك؛ احفظ نسخة احتياطية قبل ذلك (وصول مدير الملفات لمجلد `Android/data` محدود في Android 11+، لذلك يوجد أيضاً نسخ النص للّصق في ملاحظاتك).
- الجدول الأسبوعي ثابت في `lib/data/timetable.dart` (جدول «شريف أحمد»)؛ عدّله هناك إن تغيّر.
- التقويم ميلادي، ويُهمل الخميس والجمعة (العطلة الأسبوعية).

## قائمة الاختبار اليدوي
1. أول تشغيل وسؤال السبت 17 أكتوبر. 2. فتح تحضير اليوم ومجموع الدقائق (35 / 45).
3. تعديل نص ثم إغلاق التطبيق وفتحه: التعديل باقٍ. 4. «استعادة الأصل».
5. إضافة عطلة: تُزاح الدروس التالية. 6. وسم حصة «لم تُعقد» ثم استعادتها.
7. نسخ التحضير الكامل ولصقه في تطبيق التحضير. 8. نسخ احتياطي بملف ثم استرجاعه بعد حذف التعديلات.
9. تحضير يدوي للشعبة 12ب. 10. تدوير الشاشة وتكبير الخط.

## هيكل المشروع
- `lib/app` الثيم والتطبيق والحالة (`Store`) · `lib/database` SQLite · `lib/models` · `lib/data` (الجدول والمنهج) · `lib/services` (النسخ الاحتياطي)
- `lib/screens` (اليوم، الجدول، الدروس، الإعدادات، التحضير، النسخ الاحتياطي) · `lib/widgets` · `lib/utils`
- `android` إعدادات البناء (نفس إصدارات مشروع الجرس المدرسي) · `test`
